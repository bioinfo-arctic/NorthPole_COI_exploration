# NorthPole_COI_exploration
Standalone interactive dashboard for exploring surface-sample taxonomic composition north of Svalbard. Features a clickable map, sample comparisons, technical-library stacked barplots, Kingdom/Phylum views, and CSV downloads. Runs entirely in the browser and supports GitHub Pages.  

See the web page here:  
[NorthPole_COI_exploration](https://bioinfo-arctic.github.io/NorthPole_COI_exploration/)
